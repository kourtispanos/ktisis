# 🏗️ Ktisis — Διαχείριση Εργολαβίας

Μια εφαρμογή διαχείρισης για εργολάβους/κατασκευαστές: πελάτες, έργα,
προσωπικό, οικονομικά, καιρός, ημερολόγιο και οχήματα — όλα σε ένα μέρος.

Φτιαγμένη σε **Python**, με **SQLite** για βάση δεδομένων και
**Streamlit** για το UI. Τρέχει τοπικά στον υπολογιστή σου (ή στο
τοπικό σου δίκτυο) — τα δεδομένα σου δεν φεύγουν ποτέ σε κάποιον server.

---

# Τι κάνει

| Ενότητα | Περιγραφή |
|---|---|
|  **Πελάτες** | Στοιχεία πελατών + αυτόματος υπολογισμός πληρωμένου/υπολοίπου ανά πελάτη |
|  **Έργα** | Προϋπολογισμός, ημερομηνίες, **ζωντανή** παρακολούθηση εξόδων vs προϋπολογισμού, αυτόματος υπολογισμός εργάσιμων ημερών |
|  **Προσωπικό & Ημερομίσθια** | Αυτόματος υπολογισμός αμοιβής (ημερομίσθιο × ημέρες) + σύνολα ανά εργάτη |
|  **Έξοδα & Έσοδα** | Κατηγορίες εξόδων, ποσότητα/μονάδα μέτρου, συντελεστής ΦΠΑ ανά έσοδο |
|  **Φορολογίες & Τιμολόγια** | Σύνοψη ΦΠΑ προς απόδοση, φορολογικές υποχρεώσεις, τιμολόγια με παρακολούθηση πληρωμής |
|  **Καιρός** | Τρέχων καιρός + πρόγνωση 4 ημερών για όποια πόλη θες (OpenWeatherMap) |
|  **Ημερολόγιο** | Οπτικό πλέγμα μήνα, κλικ σε ημέρα για υπενθυμίσεις (ραντεβού, σέρβις, προθεσμίες) |
|  **Οχήματα** | Ασφάλεια, ΚΤΕΟ, τέλη κυκλοφορίας, σέρβις — με αυτόματη προειδοποίηση λήξης |
|  **Αναφορές** | Μηνιαία/ετήσια αναφορά: τζίρος, έξοδα, καθαρά κέρδη, περιθώριο %, κατανομή εξόδων |
|  **Σύνδεση** | Εγγραφή/σύνδεση χρηστών με κρυπτογραφημένους κωδικούς (δεν αποθηκεύεται τίποτα σε απλό κείμενο) |

# Για απλή χρήση (χωρίς εγκατάσταση Python)

1. Κατέβασε το [`KtisisSetup.exe`](installer_output/KtisisSetup.exe)
2. Άνοιξέ το, πάτα **Next → Next → Install**
3. Η εφαρμογή ανοίγει αυτόματα στον browser σου

Δεν χρειάζεται τίποτα άλλο εγκατεστημένο — ούτε Python, ούτε GitHub.

---

# Για ανάπτυξη

```bash
# Δημιουργία virtual environment
python -m venv venv
venv\Scripts\activate

# Εγκατάσταση εξαρτήσεων
pip install -r requirements.txt

# Δημιουργία βάσης δεδομένων (πρώτη φορά μόνο)
python database/create_db.py

# Εκκίνηση
streamlit run app.py
```

# Ρύθμιση καιρού (προαιρετικό)

Το tab "Καιρός" χρειάζεται δωρεάν API key από το
[openweathermap.org](https://openweathermap.org/api). Μόλις το πάρεις,
άνοιξε το [`weather.py`](weather.py) και αντικατέστησε τη γραμμή:

```python
API_KEY = "ΒΑΛΕ_ΕΔΩ_ΤΟ_API_KEY_ΣΟΥ"
```

# Τεστ

```bash
python -m unittest discover -s tests -v
```

Κάθε τεστ τρέχει σε δική του προσωρινή βάση δεδομένων — ποτέ δεν αγγίζει
το πραγματικό `ktisis.db`.

---

# Δημιουργία exe / installer

```bash
# 1. Standalone exe (χρειάζεται pip install pyinstaller)
pyinstaller --name Ktisis --onedir --noconfirm --collect-all streamlit launcher.py

# 2. Αντιγραφή των .py αρχείων μέσα στο dist/Ktisis/ (το PyInstaller δεν τα παίρνει μόνο του)

# 3. Compile installer (χρειάζεται Inno Setup: https://jrsoftware.org)
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

Το αποτέλεσμα είναι το `installer_output\KtisisSetup.exe`.

# Δομή project

```
ktisis/
├── app.py                 UI — όλα τα tabs (Streamlit)
├── main.py                Στιγμιότυπο βάσης στο terminal
├── launcher.py             Σημείο εκκίνησης για το πακεταρισμένο exe
│
├── clients.py              Πελάτες
├── projects.py             Έργα + προϋπολογισμός + εργάσιμες μέρες
├── workers.py               Προσωπικό
├── wage_entries.py           Ημερομίσθια
├── expenses.py              Έξοδα
├── income.py                Έσοδα + ΦΠΑ
├── invoices.py               Τιμολόγια
├── taxes.py                 Φορολογικές υποχρεώσεις
├── vehicles.py               Οχήματα
├── calendar_events.py        Ημερολόγιο/υπενθυμίσεις
├── weather.py                Εξωτερικό API καιρού
├── reports.py                Μηνιαίες/ετήσιες οικονομικές αναφορές
│
├── auth.py                  Hashing κωδικών (pbkdf2 + salt)
├── users.py                  Εγγραφή/σύνδεση χρηστών
│
├── database/
│   ├── db.py                 Κοινή σύνδεση με τη βάση
│   └── create_db.py          Δημιουργία/migration πινάκων
│
├── tests/                   Αυτοματοποιημένα τεστ (unittest)
├── installer.iss             Script για το Inno Setup
└── requirements.txt
```

Κάθε αρχείο ακολουθεί το ίδιο μοτίβο: `add_x()`, `update_x()`,
`delete_x()`, `list_x()` — προβλέψιμο και εύκολο στην πλοήγηση.

## ⚠️ Σημειώσεις

- Οι υπολογισμοί ΦΠΑ είναι **ενδεικτικοί** — επιβεβαίωσέ τους πάντα με
  τον λογιστή σου, δεν αποτελούν φορολογική συμβουλή.
- Η εφαρμογή τρέχει **τοπικά**· δεν είναι προσβάσιμη από το internet
  εκτός αν ρυθμίσεις εσύ port forwarding στο router σου.
- Τα δεδομένα σου ζουν σε ένα αρχείο: `ktisis.db`, δίπλα στο exe/script.
  Κάνε τακτικά αντίγραφο ασφαλείας αυτού του αρχείου.
